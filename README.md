## FAQ & AI Search Readiness

- The homepage contains six visible, crawlable FAQ answers in native HTML `<details>` elements.
- A matching `FAQPage` JSON-LD block is included. Structured data must match visible page content.
- Important profile and service information is present as readable HTML, not hidden behind client-side rendering.
- The `Person` entity uses profile links in `sameAs` and relevant `knowsAbout` topics. Keep these links and claims accurate.
- No `llms.txt` file is added as an SEO ranking tactic. Google's guidance does not require such files or special AI markup for Google Search visibility. Focus on crawlability, useful original content, clear structure, accurate facts, and page experience.
- FAQ structured data does not guarantee a Google FAQ rich result. Google limits FAQ rich results primarily to well-known authoritative government and health websites, so a personal portfolio should treat FAQs as useful on-page content and semantic markup, not a promised search result feature.

## Typography & Sticky Header

- Body and supporting text sizes have been increased for readability.
- Desktop and mobile heading scales have been adjusted.
- The sticky header remains pinned to the top while scrolling. The outer shell uses `overflow: clip` so it does not create a scrolling ancestor that interferes with sticky positioning.
